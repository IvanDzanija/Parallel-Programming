# Parallel Programming

This repository contains solutions and supporting code for the **Parallel
Programming** course labs at FER.

## Description

Laboratory exercises focus on the development and optimization of parallel
algorithms using various paradigms. The labs cover distributed memory
parallelism using MPI for synchronization and communication between processes,
as well as heterogeneous computing using OpenCL to exploit GPU acceleration for
computationally intensive tasks.

## Laboratory Exercises

- **Lab 1 – Message Passing Interface (MPI)**
    - Introduction to distributed memory parallelism
    - Implementation of synchronization problems like the Dining Philosophers
      using MPI communication primitives

- **Lab 2 – Advanced MPI and Task Decomposition**
    - Developing parallel search algorithms for games and optimization
    - Implementing task splitting and load balancing strategies in a
      distributed environment

- **Lab 3 – GPU Programming with OpenCL**
    - Offloading computations to graphics processors for massive parallelism
    - Implementing kernel-based algorithms for numerical simulations like pi
      calculation and prime number identification
    - Parallelizing a Computational Fluid Dynamics (CFD) solver using OpenCL
